## Seed Book (AI image browser)
本应用是一款桌面软件，用于集中管理和查看主要由生成式AI（如Stable Diffusion）创作的图像及其相关元数据（包括提示词、反向提示词、模型参数等）。特别针对Stability Matrix生成的图像进行了优化，与其他文件管理工具搭配使用会非常方便。

> **开发初衷** <br>
> Stability Matrix生成的图像会统一输出到"inference"文件夹，但其默认预览界面的排版让我感觉很难浏览，这正是我开发本应用的初衷：希望有一款工具，能够在不修改原始文件的前提下，随时舒适地浏览大量图像。虽然最初是为Stability Matrix而设计，但作为通用图像查看器使用同样很方便。
>
> **关于开发方式** <br>
> 我本人并不具备专业的编程背景，本应用是通过与AI编程工具持续对话来设计和实现功能的，也就是所谓的"氛围编程（vibe coding）"。具体来说，我在开发过程中一直使用Anthropic的Claude（Sonnet）作为开发伙伴。但这并不意味着随意开发：每次新增功能后都会亲自进行实际操作验证，并在独立的干净用户账户中进行测试，正式发布前也会经过Apple公证等正规流程。

> **关于应用界面语言** <br>
> 应用本体自v1.3.0起，可在设置中将界面语言切换为日语或英语（自动/日本語/English），暂不支持中文界面。本说明文档提供中文版本，是为了方便中文用户了解本应用；如有需要，欢迎通过英语或日语界面使用。

更详细的使用说明请参阅 [manual.md](./manual.md)（英文）或 [manual.ja.md](./manual.ja.md)（日文）。

## 如何运行应用
在本地环境启动应用的步骤如下。

### 1. 安装依赖包
在Python（推荐3.10以上）环境的终端或虚拟环境中，执行以下命令安装所需的库。

```bash
pip install -r requirements.txt
```

### 2. 启动应用
进入文件所在目录，运行入口文件 `main.py`。

```bash
python main.py
```

## 文件结构
本项目由以下5个核心文件模块化组成：

#### 1. `main.py`（入口文件）
应用程序的启动入口，负责初始化GUI并显示主窗口。

#### 2. `app.py`（核心逻辑）
基于PySide6的整体UI、事件处理、搜索（筛选）、排序与分组显示、幻灯片播放、剪贴板联动、深色/浅色主题切换、设置对话框等功能均由此文件负责。

#### 3. `importer.py`（数据提取）
使用Pillow从图像中自动提取元数据，并计算文件内容的SHA-256哈希值，处理文件夹同步。

#### 4. `database.py`（数据库）
使用SQLite3持久化保存图像信息和导入历史。具备自动迁移功能，可灵活应对数据库结构变更。

#### 5. `.gitignore`（排除设置）
指定不纳入版本管理的文件，如缓存文件、虚拟环境（`venv`）、数据库文件（`image_metadata*.db`），以及记录当前使用中数据库的指针文件（`current_db.txt`）。

## 功能

#### 1. 文件夹同步与导入

**差量自动导入** <br>
记住已导入的文件夹路径，点击"同步（Sync）"按钮即可快速扫描并仅添加新图像。文件夹导入与同步均不包含子文件夹（仅扫描所选文件夹内的文件）。

**导入顺序确认** <br>
导入文件夹时，可从按文件名、创建时间、修改时间（各含升序/降序）中选择导入顺序。设置界面中可选择"每次确认"（默认）或"自动使用上次的顺序"。

**单独文件导入** <br>
除了按文件夹导入外，还可以单独选择多个图像文件进行导入，适合不想导入整个文件夹的情况。

**自动连号命名** <br>
新导入图像的"名称"默认不使用实际文件名，而是自动附加连续编号（例如：CG_00001）。前缀、位数、以及附加在末尾的字符串均可在设置界面中修改。每种"前缀+附加字符串"组合各自独立计数，删除后编号也不会被重复使用（可在设置界面手动重置）。也可以通过设置界面的复选框关闭连号命名功能，直接使用实际文件名作为"名称"导入。前缀/附加字符串栏支持`{日付}`（日期）和`{フォルダ名}`（文件夹名）占位符——点击占位符链接即可插入到当前光标所在的栏位（前缀或附加），并自动在相应一侧加上下划线。

**按文件夹单独设置命名规则** <br>
在"按文件夹分组显示"中右键点击文件夹标题，可为该文件夹单独设置前缀/位数/附加字符串规则，覆盖应用全局的默认设置。此覆盖不仅适用于导入该文件夹的新图像，也适用于对该文件夹内已有图像执行的"批量重命名"和"批量导出并重命名"。

**可选择的导入格式** <br>
PNG / JPG / JPEG / WEBP 默认启用；GIF / BMP / TIFF 可通过复选框启用（GIF 仅显示第一帧作为静止图像）。复选框区域自带显示/隐藏切换按钮，方便保持列表区域简洁。

**防止重复导入** <br>
通过比较文件路径重复情况以及文件内容的**SHA-256哈希值**，自动跳过内容相同的图像（副本）。在导入确认界面中选择"同时导入内容相同的图像"，也可以将其作为独立记录导入（默认为跳过）。

**后台处理** <br>
大量导入时会显示进度对话框（数量、当前文件名），并可以在需要时中途取消。

#### 2. 查看器

**参数自动分离** <br>
自动从图像元数据中判别并分离显示"提示词"、"反向提示词"、"其他详细信息（Steps、Sampler、Seed等）"。此外，Steps、Sampler、Scheduler、CFG scale、Seed、Size也可以作为独立项目显示在所用模型栏下方（可在设置界面中按项目分别切换显示/隐藏）。Seed数值旁边设有专用复制按钮，可单独复制该数值。

**支持的格式** <br>
除Stable Diffusion WebUI（Automatic1111 / Forge）、NovelAI外，还支持ComfyUI生成的图像。由于ComfyUI的工作流结构因用户而异，因此不会自动提取提示词等内容，而是将整个工作流（包括LoRA、批处理大小等设置）原样保存在"其他参数 / 元数据 / EXIF信息"栏中。

**相机EXIF信息显示** <br>
对于未检测到AI生成参数的照片（JPEG/TIFF/WEBP等原生支持EXIF的格式），应用会自动读取相机EXIF信息——厂商、机型、拍摄时间、曝光时间、光圈值、ISO感光度、焦距、GPS坐标——并整理显示在"其他参数 / 元数据 / EXIF信息"栏中。PNG/GIF/BMP格式不支持此功能（因为它们本身不带有原生EXIF）。

**逐图备注栏** <br>
编辑区域最上方有一个自由填写的备注栏，与AI生成的元数据完全无关，仅供您在应用内自行记录使用。填写的内容也会被纳入搜索范围。

**一键复制** 点击各提示词区域旁边的按钮，即可将文本复制到剪贴板。

**星级评分** <br>
将鼠标悬停在星星上会显示预览，点击可设置0〜5级评分。再次点击同一颗星可取消评分。

**预览显示切换** <br>
可从"隐藏"、"标准"、"紧凑"、"全屏"4种预览尺寸中选择。选择"隐藏"可为元数据编辑区域腾出更多空间。即使在全屏显示中，切换图像、幻灯片播放、播放速度等操作仍可正常使用。

**拖出预览图像** <br>
预览中的图像可直接拖拽到Finder（资源管理器）或其他应用中，以副本形式取出。

**编辑文件名** <br>
除"名称"外，还可以直接编辑并修改（重命名）电脑上的实际文件名。同一文件夹内不允许重名。

**自由编辑名称** <br>
应用内管理的"名称"可独立于实际文件名自由编辑，也可以像搜索标签一样使用（允许重复）。

**另存为副本** <br>
不修改原始文件，将编辑后的内容作为新的副本保存到您指定的位置。

**批量重命名（仅限应用内"名称"）** <br>
选中多张图像并右键点击，选择"批量重命名（连号）..."，即可按连号命名规则（或该文件夹的专属规则，如已设置）批量修改这些图像应用内的"名称"栏。**不会改变电脑上的实际文件名。**编辑锁定中的图像会被跳过，且不同`{文件夹名}`分组各自独立从1开始计数。

**批量导出并重命名（实际文件名）** <br>
选中图像（或整个文件夹标题）并选择"批量导出并重命名（连号）..."，会将原图原样复制到您指定的文件夹，并按命名规则对**副本**的实际文件名进行连号重命名。这与上面的"批量重命名"功能有意区分开，以便始终清楚区分改的是应用内名称还是电脑上的真实文件。

**清除元数据** <br>
所用模型、提示词、反向提示词、备注、其他元数据的各栏均可一键清除。由于在点击"保存更改"之前不会生效，因此即使误操作也无需担心。

**编辑表单显示/隐藏切换** <br>
备注、所用模型、提示词、反向提示词、其他元数据的各栏均可临时隐藏，各自都有独立的显示/隐藏按钮。隐藏部分腾出的高度会自动均匀分配给其余显示中的栏目。生成参数的独立显示栏也会跟随所用模型栏的显示/隐藏状态联动切换。右上角（设置图标旁）还有一个一键按钮，可将上述所有编辑栏及导入格式复选框区域一并显示/隐藏。

**图像列表提示信息** <br>
当尚未导入任何图像时，列表中会显示"请导入图像"的提示；从外部拖拽文件时会显示"请拖放至此"的提示（目前拖放导入功能本身已暂时禁用，详情请参阅下文）。

**图标设计** <br>
主要按钮和标题采用基于Google Material Symbols的图标。图标颜色会根据当前主题（深色/浅色）以及强调色（蓝色）背景按钮自动调整，确保始终清晰可辨。

#### 3. 桌面集成与操作体验

**安全的拖放操作** 可将应用内图像列表中的图像拖拽到系统文件夹（Finder/资源管理器等）或其他应用中。仅执行复制操作（原始文件受到保护）。

**右键菜单** <br>
右键点击图像可执行"在Finder（资源管理器）中显示"、"复制文件本身"、"复制路径"等操作。支持多选。

**深色/浅色主题切换** <br>
可自动跟随macOS的外观模式，也可以在设置界面中手动选择"自动/深色固定/浅色固定"。

**左右面板布局切换** <br>
可在设置界面中选择搜索、导入、列表等区域显示在左侧还是右侧（标准/镜像），方便惯用右手或左手的用户切换到更顺手的布局。

**编辑锁定功能** <br>
可通过右键菜单为每张图像单独锁定/解锁编辑。锁定期间无法删除或修改信息，可保护重要图像免受误操作影响。

**已删除图像不参与同步** <br>
从列表中删除的图像，即使之后再次执行"同步"也不会自动恢复。如需重新导入，请通过"导入文件夹"或"导入图像文件"重新明确选择。

**设置界面（⚙）** <br>
提供统一的设置界面，包括连号命名规则（开关切换、前缀、位数、附加字符串、按组合重置编号）、生成参数独立显示项目切换、主题与左右面板布局的手动切换、文件夹导入顺序设置、数据库初始化、图像列表CSV导出、多数据库的创建与切换、以及设置的整体重置。帮助与更新日志的链接可从主窗口顶部（设置按钮左侧）打开。

**多数据库切换** <br>
可根据不同用途创建并切换多个数据库（`image_metadata.db`、`image_metadata2.db`……）。创建与切换操作均在设置界面中进行，切换时应用会自动重启。数据库保存位置为`~/Library/Application Support/AIImageViewer/`。

#### 4. 搜索、排序与幻灯片播放

**实时筛选** <br>
根据输入的关键词（应用内"名称"栏、实际文件名、提示词、反向提示词、其他元数据）或星级评分，实时筛选列表。

**排序** <br>
可按名称、创建日期、编辑日期、导入日期、评分、文件大小排序，升序/降序可通过独立按钮切换。网格显示与列表显示也可一键切换。

**缩略图大小调整** <br>
网格显示时，可从"小/中/大"3档中选择图块大小。"大"档还会显示位置和日期信息。

**按文件夹分组显示** <br>
列表显示时，可按文件夹对图像进行分组显示。点击标题行可折叠/展开该文件夹的图像列表（以▼/▶表示状态）。右键点击标题行可通过拖放调整文件夹的排列顺序。开关状态、折叠状态及排列顺序会在下次启动时保留。

**幻灯片播放** <br>
内置基于计时器的自动播放功能。播放速度可在0.5倍〜2倍范围内以0.25为单位调整，也可仅对搜索筛选后的图像进行自动循环播放。

**阅读模式（跨页显示）** <br>
以书本翻页的形式，将所选图像所在文件夹内的图像两两并排全屏显示（仅在启用"按文件夹分组显示"时可用）。支持左开/右开切换，可通过滑动条、方向键或点击屏幕边缘翻页，并支持独立于应用主题的深色/浅色背景切换。还可切换为"居中对齐显示"，使左右两页像实体书一样在屏幕中央紧密拼合。仅供浏览，不可编辑。

## 已知限制

**拖放导入功能暂时禁用** <br>
由于运行不够稳定，目前已暂时禁用从外部（如Finder）直接拖放图像到图像列表进行导入的功能。请改用"导入文件夹"/"导入图像"按钮。
