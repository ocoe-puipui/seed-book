## Seed Book (AI image browser)
主に生成AI（Stable Diffusionなど）で作成された画像と、そのメタデータ（プロンプト、ネガティブプロンプト、モデルパラメータ等）を一元管理・閲覧するデスクトップアプリです。<br>
Stability Matrix で作成した画像に最適化していますが、他のファイル管理ツールと併用しても便利にお使いいただけます。

> **開発の背景** <br>
> Stability Matrixの「inference」フォルダに一括出力される画像を、標準のプレビュー機能より見やすく扱いたいという動機から開発しました。オリジナルの画像ファイルを一切変更せず、大量の画像を快適にプレビューできるツールを目指しています。
>
> **開発について** <br>
> プログラミングの専門知識を持たず、AI（Anthropic Claude / Sonnet）との対話で設計・実装する、いわゆる「バイブコーディング」で開発しています。機能追加のたびに動作確認を行い、クリーン環境でのテストやApple公証など正規の配布手順を踏んだ上で提供しています。

より詳しい操作方法は [manual.ja.md](./manual.ja.md) をご覧ください（[English manual](./manual.md) もあります）。<br>
設定画面から表示言語（自動／日本語／English）を切り替えられます。

📖 開発の進捗・雑感は [開発日記](https://ocoe-puipui.github.io/diary/) でも公開しています。

## Technical Stack

**Language** Python 3.10+

**GUI Framework** PySide6 (Qt for Python)

**Image Processing** Pillow (PIL)

**Database** SQLite3

**OS Compatibility** Cross-platform compatible

**AI Coding Partner** Anthropic's Claude (Sonnet)

## アプリケーションの起動方法

### 1. 依存パッケージのインストール
```bash
pip install -r requirements.txt
```

### 2. アプリの起動
```bash
python main.py
```

## ファイル構成
モジュール化された以下5つのコアファイルで構成されています。

#### 1. `main.py` (エントリーポイント)
アプリ起動のエントリーポイント。GUIを初期化し、メインウィンドウを表示します。

#### 2. `app.py` (コアロジック)
PySide6によるUI全体、検索・並び替え・グループ表示、スライドショー、クリップボード連携、ダーク/ライトモード切替、設定ダイアログなどを担います。

#### 3. `importer.py` (データ抽出)
Pillowで画像からメタデータを自動抽出し、SHA-256ハッシュを計算してフォルダ同期処理を行います。

#### 4. `database.py` （データベース）
SQLite3で画像情報・インポート履歴を永続化。自動マイグレーションでDB構造の変更にも対応します。

#### 5. `.gitignore` (除外設定)
キャッシュ、仮想環境 (`venv`)、DBファイル (`image_metadata*.db`)、現在使用中DBのポインタ (`current_db.txt`) を除外します。

## 機能

#### 1. フォルダ同期 ＆ インポート

**差分自動取り込み** <br>
インポート済みフォルダを記憶し、「Sync」ボタンで新しい画像だけを追加スキャンします。サブフォルダは対象外（指定フォルダ直下のみ）です。

**取り込み順序の確認** <br>
ファイル名順・作成日時順・更新日時順（昇順/降順）から取り込み順序を選べます。設定画面で「毎回確認」（既定）か「前回の順序を自動選択」かを選択できます。

**個別ファイルの取り込み** <br>
フォルダ単位に加え、画像ファイルを個別に複数選択して取り込むこともできます。

**連番による自動命名** <br>
新規取り込み画像の「名前」には既定で連番（例: CG_00001）が自動で付きます。プレフィックス・桁数・アペンド文字列は設定画面から変更可能で、組み合わせごとに採番が独立しています（削除しても番号は再利用されません）。命名規則自体をオフにし、実ファイル名をそのまま使うこともできます。

**重複防止** <br>
ファイルパスとSHA-256ハッシュ値を比較し、同じ画像の重複登録を自動スキップします（確認画面から意図的に重複取り込みも可能）。

**バックグラウンド処理** <br>
大量インポート時は進捗ダイアログを表示し、途中キャンセルもできます。

#### 2. ビューワー

**パラメータの自動分離** <br>
画像内メタデータから「プロンプト」「ネガティブプロンプト」「その他詳細情報（Steps, Sampler, Seed等）」を自動判別・分離表示します。Steps・Sampler・Scheduler・CFG scale・Seed・Sizeは個別項目としても表示可能（設定画面で項目ごとに切替）。Seed値はワンクリックコピーに対応します。

**対応フォーマット** <br>
Stable Diffusion WebUI（Automatic1111 / Forge）・NovelAI・ComfyUIに対応。ComfyUIはワークフローの個人差が大きいため自動抽出は行わず、ワークフロー全体を「その他パラメータ」欄にそのまま保存します。

**ワンクリックのコピー** 各プロンプトエリア横のボタンでクリップボードへコピーできます。

**星評価** <br>
星にマウスを乗せてプレビュー、クリックで0〜5段階評価。同じ星を再クリックすると解除されます。

**プレビュー表示の切替** <br>
非表示・標準・コンパクト・全画面の4種類。「非表示」でメタデータ編集エリアを広く使えます。全画面中も画像送り・スライドショー操作は可能です。

**プレビュー画像のドラッグ&ドロップ** <br>
Finder（エクスプローラー）や他アプリへ直接ドラッグ&ドロップしてコピーを取り出せます。

**ファイル名の編集** <br>
「名前」とは別に、実ファイル名も直接編集（リネーム）できます（同フォルダ内での重複不可）。

**名前の自由な編集** <br>
アプリ内の「名前」は実ファイル名と独立して自由に編集でき、検索用タグのような使い方もできます（重複可）。

**変更をコピーとして保存** <br>
オリジナルは変更せず、編集内容を持つ新しいコピーとして好きな場所に保存できます。

**メタデータのクリア** <br>
使用モデル・プロンプト・ネガティブプロンプト・その他メタデータの各欄をワンクリックでクリアできます（「変更を保存」まで確定しません）。

**編集フォームの表示/非表示切替** <br>
各欄を一時的に非表示にでき、空いた高さは残りの欄に自動配分されます。使用モデル欄の表示状態に応じて生成パラメータの個別表示欄も連動します。

**画像リストの案内表示** <br>
画像が0件の時や外部ドラッグ中はリスト内に案内を表示します（現在、ドラッグ&ドロップでの取り込み自体は一時的に無効化中。詳細は下記参照）。

**アイコンデザイン** <br>
Google Material Symbolsベースのアイコンを採用し、テーマやボタン背景色に応じて自動で色が切り替わります。

#### 3. デスクトップ連携＆操作性

**安全なドラッグ＆ドロップ** アプリ内の画像リストからOSのフォルダや別アプリへドラッグして持ち出せます（コピーのみ、オリジナルは保護）。

**右クリックメニュー** <br>
Finderでの表示、ファイルのコピー、パスのコピーが行えます（複数選択対応）。

**ダーク/ライトモードの切替** <br>
OSの外観設定に自動追従、または設定画面から手動固定も可能です。

**左右パネルの配置切替** <br>
設定画面から検索・取り込み・リスト等の表示位置（標準／反転）を選べます。

**編集ロック機能** <br>
右クリックメニューから画像ごとに編集をロック/解除できます。ロック中は削除・情報変更ができません。

**削除画像の同期除外** <br>
削除した画像は「同期」を実行しても自動復活しません。再取り込みは明示的な操作が必要です。

**設定画面（⚙）** <br>
連番命名規則、生成パラメータの個別表示切替、テーマ・パネル配置、フォルダ取り込み順序、DB初期化、CSVエクスポート、複数DB管理、設定リセットをまとめています。ヘルプ・リリースノートはメインウィンドウ上部から開けます。

**複数データベースの切り替え** <br>
用途ごとに複数DB（`image_metadata.db`、`image_metadata2.db`...）を作成・切替できます（切替時は自動再起動）。保存先は`~/Library/Application Support/AIImageViewer/`です。

#### 4. 検索＆並び替え＆スライドショー

**リアルタイム絞り込み** <br>
キーワード（名前・実ファイル名・プロンプト・ネガティブプロンプト・その他メタデータ）や星の数でリストをフィルタリングします。

**並び替え** <br>
名前順・作成日順・編集日順・取り込み日時順・評価順・ファイルサイズ順から選択、昇順/降順は独立ボタンで切替。グリッド/リスト表示もワンクリック切替できます。

**サムネイルサイズ調整** <br>
グリッド表示時、タイルサイズを「小/中/大」から選べます（「大」は場所・日時も表示）。

**フォルダ別グループ表示** <br>
リスト表示時、フォルダ別にグループ化できます。見出し行クリックで折りたたみ/展開、右クリックでドラッグ&ドロップによる並び替えが可能です。状態は次回起動時まで記憶されます。

**スライドショー** <br>
タイマーによる自動再生。再生速度は0.5倍〜2倍の範囲で0.25刻み調整でき、検索絞り込み後の画像のみを巡回対象にもできます。

**読書モード（見開き表示）** <br>
同一フォルダ内の画像を本のように2枚並べて全画面表示するモードです（「フォルダ別グループ表示」中またはアルバム内画像選択時に利用可能）。左開き/右開き切替、ページめくり操作、中央詰め表示に対応した閲覧専用モードです。

#### 5. アルバム（仮想フォルダ）機能（v1.4〜）

**実フォルダを横断してまとめる仮想的な入れ物** <br>
実際のフォルダ構成とは別に画像を自由にまとめる「アルバム」を作成できます。1枚の画像を複数アルバムに同時所属させることも可能。画像リスト表示とアルバム表示は上部の切り替えボタンでどちらか一方に切り替えます。

**アルバムへの追加方法** <br>
右クリックメニューの「アルバムに追加」（既存選択、または新規作成しつつ追加）と、画像をアルバム行へドラッグ&ドロップする方法に対応しています。

**アルバム作成時に自動採番ルールも設定可能** <br>
「アルバムを作成する」ダイアログでは、名前入力とあわせて専用の自動採番ルール（プレフィックス・桁数・アペンド）を同時設定できます（既定オフ＝アプリ全体の既定ルールを使用）。{アルバム名}・{日付}のプレースホルダーが使えます。

**アルバム一覧の操作感はフォルダ別グループ表示と共通** <br>
見出し行クリックで展開/折りたたみ、右クリック（または「⋯」アイコン）でメニューを開けます。並び順編集、名前変更、一括展開/折りたたみ、一括書き出し（連番リネーム）、専用採番設定、削除に対応しています。

**アルバム専用の自動採番ルール** <br>
設定すると一括リネーム・連番書き出しに優先適用されます（フォルダ専用ルールやアプリ全体の既定ルールとは独立）。1枚のみの選択でも一括採番できます。

**Finderへの書き出し** <br>
アルバムや展開中のアルバム内画像をFinderへドラッグ&ドロップで書き出せます。アルバムは実フォルダを持たないため一時フォルダへ実体化して渡す方式で、この場合は元のファイル名がそのまま使われ採番ルールは適用されません（採番したい場合は右クリックメニューの「一括で書き出す」をご利用ください）。

**検索・並び替えとの連携** <br>
アルバム表示中も検索・並び替え（種類・昇順/降順）が反映されます。

## 既知の制限事項

**ドラッグ&ドロップでの取り込みは一時的に無効化中** <br>
外部から画像リストへ直接ドラッグ&ドロップして取り込む機能は動作が不安定なため無効化しています。「フォルダを取り込む」「画像を取り込む」ボタンをご利用ください。

**フォルダ別グループ表示で、折りたたみ操作後に画像送りが反応しないことがある** <br>
表示中の画像を含むフォルダを折りたたんだ後、画像送り操作が正しく反応しないことがあります。致命的ではないため、修正は今後の課題としています。
