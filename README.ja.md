## Seed Book (AI image browser)
主に生成AI（Stable Diffusionなど）の画像とそのメタデータ（プロンプト、ネガティブプロンプト、モデルパラメータ等）を一元管理・閲覧するデスクトップアプリ。Stability Matrixの出力に最適化されており、他のファイル管理ツールとも併用できます。

> **開発の背景** — Stability Matrixの生成画像は「inference」フォルダに一括出力されますが標準プレビューが見づらく開発しました。オリジナルを変更せず大量の画像を快適にプレビューすることが目標です。専用ではなく汎用画像ビューワーとしても使えます。
>
> **開発について** — 私はプログラミングの専門知識を持たず、AIとの対話で設計・実装する「バイブコーディング」で開発しています。Claude（Sonnet）を開発パートナーに、機能追加のたびに動作確認を行い、別ユーザーアカウントでのクリーン環境テストやAppleの正式な公証など正規の手順を踏んでいます。

詳しい操作方法は [manual.ja.md](./manual.ja.md)（[English版](./manual.md) もあり）。v1.3.0〜、設定画面から表示言語を切替可能。📖 開発の進捗・雑感は [開発日記](https://ocoe-puipui.github.io/diary/) で公開中。

## Technical Stack
**Language** Python 3.10+ ／ **GUI** PySide6 ／ **画像処理** Pillow (PIL) ／ **DB** SQLite3 ／ **OS** クロスプラットフォーム ／ **AI開発パートナー** Claude (Sonnet)

---

## アプリケーションの起動方法

### 1. 依存パッケージのインストール
以下のコマンドで必要なライブラリをインストールします。
```bash
pip install -r requirements.txt
```

### 2. アプリの起動
ファイルのあるディレクトリに移動し、`main.py` を実行します。
```bash
python main.py
```

## ファイル構成
以下5つのコアファイルで構成されています。

| ファイル | 役割 |
|---|---|
| `main.py` | エントリーポイント — GUI初期化とメインウィンドウ表示。 |
| `app.py` | コアロジック — UI、イベント、検索・並び替え・グループ、スライドショー、クリップボード、テーマ切替、設定。 |
| `importer.py` | データ抽出 — Pillowでメタデータ自動抽出、SHA-256ハッシュ計算、フォルダ同期。 |
| `database.py` | データベース — SQLite3で永続化、自動マイグレーション対応。 |
| `.gitignore` | 除外設定 — `venv`、`__pycache__`、`image_metadata*.db`、`current_db.txt`（使用中DBポインタ）。 |

## 機能

#### 1. フォルダ同期＆インポート
- **差分自動取り込み** — フォルダのパスを記憶し「Sync」で新しい画像だけを追加スキャン（直下のみ、サブフォルダ除外）。個別の複数選択取り込みにも対応、順序は毎回確認（既定）または前回選択を自動再利用。PNG/JPG/JPEG/WEBPが既定で有効、GIF/BMP/TIFFはチェックで切替（GIFは1コマ目表示）。SHA-256ハッシュで重複を既定で自動スキップ（別レコード化も可）、大量インポートは進捗ダイアログでキャンセル可能。
- **連番による自動命名** — 新規画像の「名前」は既定で連番（例: `CG_00001`）。プレフィックス・桁数・アペンド文字列は設定で変更可能、組み合わせごとに採番が独立し削除後も番号は再利用されません（手動リセット可）。オフで実ファイル名を使用、`{date}`・`{folder name}`対応。フォルダ見出しの右クリックでフォルダ単位の規則も設定でき、Bulk Rename/Exportにも適用。

#### 2. ビューワー
- **パラメータの自動分離・EXIF・メモ欄** — メタデータを「プロンプト」「ネガティブプロンプト」「その他詳細」に自動分離表示。Steps/Sampler/Scheduler/CFG scale/Seed/Sizeはモデル欄下に個別表示も可（Seedに専用コピーボタン）。SD WebUI（Automatic1111/Forge）・NovelAI・ComfyUI対応（ComfyUIは自動抽出せず「その他パラメータ」に保存）。AI情報のない写真（JPEG/TIFF/WEBP）はカメラEXIF（メーカー・機種・日時・露出・F値・ISO・焦点距離・GPS）を同欄に表示（PNG/GIF/BMP非対応）。編集エリア上部に検索可能なメモ欄もあります。
- **コピー・星評価・プレビュー切替** — 各プロンプト欄のボタンでワンクリックコピー。星はホバーでプレビュー、クリックで0〜5段階設定、再クリックで解除。プレビューは非表示・標準・コンパクト・全画面から切替（全画面中も操作可）、Finder等へ直接D&Dで取り出せます。アプリ内「名前」は実ファイル名と別に自由編集でき検索用タグにも使えます（重複可）。実ファイル名も直接編集・リネーム可（同フォルダ内重複不可）。オリジナルを変更せず新しいコピーとして保存も可。
- **一括リネーム／一括書き出し（連番）** — 「Bulk Rename」は連番規則（またはフォルダ別規則）でアプリ内「名前」だけを一括変更（**実ファイル名は不変**、ロック中は除外、`{folder name}`ごとに1から採番）。「Bulk Export with Rename」はオリジナルを指定フォルダへ連番複製としてコピー — 影響範囲が分かるよう別コマンドです。各欄はワンクリックでクリア可能（保存まで未確定）、個別に非表示にでき空いた高さは自動配分。1ボタンで全欄＋取り込み形式チェックを一括切替。
- **案内表示・アイコン** — 未登録時・ドラッグ中は案内表示（D&D取り込みは現在無効化）。主要ボタン・見出しはアイコンでテーマに自動調整。

#### 3. デスクトップ連携＆操作性
- **ドラッグ＆ドロップ／右クリック／テーマ** — 画像リストからOSフォルダや別アプリへドラッグして持ち出せます（コピーのみ、複数選択対応）。右クリックでFinder表示、ファイル/パスのコピー、編集ロック/解除（ロック中は削除・変更不可）。ダーク/ライトはmacOS設定に自動追従または固定可、検索・取り込み・リストは左右どちらに表示するか選べ利き手に対応。削除画像は「同期」後も自動復活せず、再取り込みには明示的な選び直しが必要。
- **設定画面（⚙）** — 連番命名規則、生成パラメータ表示切替、テーマ・パネル配置、取り込み順序、DB初期化、CSVエクスポート、複数DB作成・切替（自動再起動、保存先`~/Library/Application Support/AIImageViewer/`）、全体リセットを提供。ヘルプ・リリースノートはウィンドウ上部から。

#### 4. 検索＆並び替え＆スライドショー
- **絞り込み・並び替え・サムネイル** — キーワード（名前/実ファイル名/プロンプト/ネガティブプロンプト/その他）や星の数で瞬時に絞り込み。名前・作成日・編集日・取り込み日時・評価・サイズ順、昇順/降順を独立切替、グリッド/リスト表示もワンクリック切替。グリッドタイルは「小/中/大」（「大」は場所・日時も表示）、リストはフォルダ別グループ化（見出しクリックで折りたたみ/展開▼/▶、右クリックで並び替え、状態と順序は次回起動時まで記憶）。
- **スライドショー** — タイマー自動再生、速度0.5〜2倍を0.25刻みで調整、絞り込み画像だけの巡回も可。
- **読書モード（見開き表示）** — 同じフォルダの画像を本のように2枚並べ全画面表示（「フォルダ別グループ表示」時、またはアルバム内選択時）。左開き/右開き、スライドバー・矢印キー・端クリックでページめくり、ダーク/ライト切替、中央詰め。閲覧専用。

#### 5. アルバム（仮想フォルダ）機能（v1.4〜）
- **実フォルダを横断する仮想の入れ物** — フォルダ構成とは別に画像を自由にまとめられ、1枚が複数アルバムに所属可能。リスト/アルバム表示は上部ボタンで排他的に切替。右クリック→「アルバムに追加」、またはアルバム行へD&Dで追加。
- **アルバム一覧の操作・自動採番** — 見出しクリックで展開/折りたたみ、右クリック（または「⋯」）で並び順編集、名前変更、すべて開く/折りたたむ、一括書き出し（連番リネーム）、採番設定、削除。採番ルールは作成時/後から設定可（プレフィックス・桁数・アペンド、既定オフ、{アルバム名}・{日付}対応）、設定時は一括リネーム・連番書き出しに優先適用（独立、1枚でも可）。
- **Finderへの書き出し** — アルバムや画像をFinderへドラッグ&ドロップで書き出せます。アルバムは実フォルダを持たないため一時フォルダへ実体化され、元のファイル名がそのまま使われます（採番は専用の連番書き出しを利用）。検索・並び替えもアルバム表示中に機能。

## 既知の制限事項

**ドラッグ&ドロップでの取り込みは一時的に無効化中** — 外部（Finder等）から画像リストへの直接D&D取り込みは動作が不安定なため無効化。「フォルダを取り込む」「画像を取り込む」ボタンをご利用ください。

**折りたたみ後に画像送りが反応しないことがある** — フォルダ別グループ表示で表示中画像のフォルダを折りたたむと画像送りが正しく反応しないことがあります。致命的ではなく、修正は今後の課題です。
