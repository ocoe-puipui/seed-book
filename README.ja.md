## Seed Book (AI image browser)
生成AI（Stable Diffusionなど）で作成された画像と、そのメタデータ（プロンプト、モデルパラメータ等）を一元管理・閲覧するデスクトップアプリです。Stability Matrix向けに最適化していますが、他のファイル管理ツールとの併用にも便利です。

> **開発の背景** <br>
> Stability Matrixの出力は「inference」フォルダに一括保存され、標準プレビューが見づらかったのが開発のきっかけです。オリジナルを変更せず快適にプレビューできるツールを目指しました。汎用の画像ビューワーとしても使えます。
>
> **開発について** <br>
> 私自身はプログラミングの専門知識を持たず、AIとの対話でコードを設計・実装する「バイブコーディング」で開発しています。AnthropicのClaude（Sonnet）を開発パートナーとして利用しつつ、機能追加のたびに動作確認、クリーン環境テスト、Appleの正式な公証を経て提供しています。

より詳しい操作方法は [manual.ja.md](./manual.ja.md) をご覧ください（[English manual](./manual.md) もあります）。<br>
v1.3.0〜、設定画面から表示言語（自動／日本語／English）を切り替えられます。

📖 開発の進捗・雑感は [開発日記](https://ocoe-puipui.github.io/diary/) でも公開しています。

## Technical Stack

**Language** Python 3.10+

**GUI Framework** PySide6 (Qt for Python)

**Image Processing** Pillow (PIL)

**Database** SQLite3

**OS Compatibility** Cross-platform compatible

**AI Coding Partner** Anthropic Claude（Sonnet）

## アプリケーションの起動方法

### 1. 依存パッケージのインストール
```bash
pip install -r requirements.txt
```

### 2. アプリの起動
```bash
python main.py
```

## ファイル構成
モジュール化された5つのコアファイルで構成されています。

#### 1. `main.py` (エントリーポイント)
GUIを初期化し、メインウィンドウを表示します。

#### 2. `app.py` (コアロジック)
PySide6によるUI全体、検索・並び替え・グループ表示、スライドショー、クリップボード連携、テーマ切替、設定ダイアログを担います。

#### 3. `importer.py` (データ抽出)
Pillowでメタデータを抽出し、SHA-256ハッシュを計算、フォルダ同期処理を行います。

#### 4. `database.py` （データベース）
SQLite3で画像情報を永続化し、自動マイグレーションでDBの構造変更にも対応します。

#### 5. `.gitignore` (除外設定)
`venv`、`__pycache__`、`image_metadata*.db`、現在のDBを示す`current_db.txt`をリポジトリから除外します。

## 機能

#### 1. フォルダ同期 ＆ インポート

**差分自動取り込み** <br>
インポート済みフォルダを記憶し、「Sync」で新しい画像だけを追加スキャンします。サブフォルダは対象外です。

**取り込み順序の確認** <br>
ファイル名・作成日時・更新日時（昇順/降順）から取り込み順序を選択。毎回確認するか、前回の順序を自動選択するかを設定できます。

**個別ファイルの取り込み** <br>
フォルダ全体ではなく、画像ファイルを個別に複数選択して取り込めます。

**連番による自動命名** <br>
新規取り込み画像には既定で連番（例: CG_00001）が付きます。プレフィックス・桁数・アペンド文字列は設定画面で変更でき、組み合わせごとに独立採番（削除後も再利用なし、手動リセット可）。オフにして実ファイル名をそのまま使うことも可能です。`{date}`・`{folder name}`のプレースホルダーはクリックで挿入できます。

**フォルダ単位の命名ルール上書き** <br>
フォルダ見出しを右クリックし、専用の命名ルールを設定できます。新規取り込みだけでなく一括リネーム・一括書き出しにも適用されます。

**取り込み形式の選択** <br>
既定はPNG/JPG/JPEG/WEBP。GIF/BMP/TIFFはチェックボックスで有効化でき、表示自体も個別に切り替えられます。

**重複防止** <br>
ファイル内容の**SHA-256ハッシュ**を比較し、ファイル名が違っても同じ内容は自動でスキップします。あえて別レコードとして取り込む選択も可能です。

**バックグラウンド処理** <br>
大量インポート時は進捗ダイアログを表示し、途中キャンセルもできます。

#### 2. ビューワー

**パラメータの自動分離** <br>
メタデータをプロンプト・ネガティブプロンプト・その他詳細情報に自動分離。Steps・Sampler・Scheduler・CFG scale・Seed・Sizeは個別表示も可能で、Seedは専用ボタンで値のみコピーできます。

**対応フォーマット** <br>
Stable Diffusion WebUI（Automatic1111 / Forge）・NovelAI・ComfyUIに対応。ComfyUIはワークフローがユーザーごとに異なるため、ワークフロー全体を「その他パラメータ」欄にそのまま保存します。

**カメラEXIF表示** <br>
AI生成メタデータのないJPEG/TIFF/WEBP写真では、機種名・日時・露出・ISO・GPS等のEXIFを自動で「その他パラメータ」欄に表示します（PNG/GIF/BMPは非対応）。

**画像ごとのメモ欄** <br>
AI生成メタデータとは独立したフリーテキストのメモ欄で、検索対象にも含まれます。

**ワンクリックのコピー** 各プロンプト横のボタンでクリップボードへコピーできます。

**星評価** <br>
星にマウスを乗せるとプレビュー表示、クリックで0〜5段階評価。同じ星を再クリックで解除できます。

**プレビュー表示の切替** <br>
非表示・標準・コンパクト・全画面から選択。全画面中も画像送り・スライドショー・速度操作が可能です。

**プレビュー画像のドラッグ&ドロップ** <br>
プレビュー中の画像をFinder等へ直接ドラッグ&ドロップしてコピーできます。

**ファイル名の編集** <br>
「名前」欄とは別に実ファイル名も直接編集・リネームできます（同フォルダ内の重複不可）。

**名前の自由な編集** <br>
アプリ内の「名前」は実ファイル名と独立して自由に編集でき、検索タグのような使い方もできます（重複可）。

**変更をコピーとして保存** <br>
オリジナルを変更せず、編集内容を新しいコピーとして好きな場所に保存できます。

**メタデータのクリア** <br>
使用モデル・プロンプト等の各欄をワンクリックでクリアでき、「保存」を押すまでは確定しません。

**編集フォームの表示/非表示切替** <br>
各メタデータ欄を一時的に非表示にでき、空いたスペースは自動で再配分されます。生成パラメータの個別表示欄も使用モデル欄の表示状態に連動します。

**画像リストの案内表示** <br>
画像未登録時やドラッグ中に案内メッセージを表示します（ドラッグ&ドロップでの取り込み自体は現在一時的に無効化中）。

**アイコンデザイン** <br>
Google Material Symbolsベースのアイコンを採用し、テーマや背景色に応じて色が自動で切り替わります。

#### 3. デスクトップ連携＆操作性

**安全なドラッグ＆ドロップ** 画像リストからOSフォルダや他アプリへドラッグでき、コピーのみが作成されます（オリジナルは保護）。

**右クリックメニュー** <br>
Finderでの表示、ファイルコピー、パスコピーが可能。複数選択にも対応します。

**ダーク/ライトモードの切替** <br>
macOSの外観設定に自動追従、または設定画面から手動固定できます。

**左右パネルの配置切替** <br>
設定画面から検索・取り込み・リスト等の左右配置（標準／反転）を選べます。

**編集ロック機能** <br>
右クリックメニューから画像ごとに編集をロック/解除でき、ロック中は削除・変更ができません。

**削除画像の同期除外** <br>
削除した画像は「同期」実行後も復活せず、再取り込み時のみ戻ります。

**設定画面（⚙）** <br>
命名規則、パラメータ表示項目、テーマ・パネル配置、取り込み順序、DB初期化、CSVエクスポート、複数DB管理、全体リセットなどをまとめています。ヘルプ・リリースノートはメインウィンドウ上部から開けます。

**複数データベースの切り替え** <br>
用途ごとに複数のDBを作成・切り替えでき（自動再起動）、保存先は`~/Library/Application Support/AIImageViewer/`です。

#### 4. 検索＆並び替え＆スライドショー

**リアルタイム絞り込み** <br>
名前・実ファイル名・プロンプト・メタデータや星の数で即座にフィルタリングします。

**並び替え** <br>
名前順・作成日順・編集日順・取り込み日時順・評価順・ファイルサイズ順から選択でき、グリッド/リスト表示も切替可能です。

**サムネイルサイズ調整** <br>
グリッド表示でタイルサイズを小/中/大から選択でき、「大」は場所・日時も表示します。

**フォルダ別グループ表示** <br>
リスト表示でフォルダ別にグループ化し、見出しクリックで折りたたみ、右クリックでドラッグ&ドロップの並び替えができます。状態は次回起動時まで記憶されます。

**スライドショー** <br>
タイマー自動再生、0.5〜2倍速を0.25刻みで調整でき、検索絞り込み中の画像のみ巡回することもできます。

**読書モード（見開き表示）** <br>
同フォルダの画像を本のように2枚並べて全画面表示します（「フォルダ別グループ表示」が必要）。左開き/右開き、複数方式でのページめくり、背景切替、中央詰め表示に対応した閲覧専用モードです。

## 既知の制限事項

**ドラッグ&ドロップでの取り込みは一時的に無効化中** <br>
Finder等から画像リストへの直接ドラッグ&ドロップは動作が不安定なため無効化中です。「フォルダを取り込む」「画像を取り込む」ボタンをご利用ください。
