## Seed Book (AI image browser)
主に生成AI（Stable Diffusionなど）によって作成された画像と、そのメタデータ（プロンプト、ネガティブプロンプト、モデルパラメータ等）を一元管理・閲覧するためのデスクトップアプリケーションです。<br>
Stability Matrix で作成した画像について最適化されたツールです。<br>
そのほかのファイル管理ツールなどと併用すると画像管理が便利になると思います。

> **開発の背景** <br>
> Stability Matrixで生成した画像は「inference」フォルダに一括出力されますが、標準のプレビュー機能ではレイアウトが見づらく感じたことがきっかけで、このアプリを開発しました。オリジナルの画像ファイルを一切変更せず、大量の画像をいつでも快適にプレビューできるツールを目指しています。Stability Matrix専用ではなく、汎用的な画像ビューワーとしてもご活用いただけます。
>
> **開発について** <br>
> 私自身はプログラミングの専門知識を持たず、AIとの対話を通じてコードを設計・実装する、いわゆる「バイブコーディング」でこのアプリを開発しています。具体的には、AnthropicのClaude（Sonnet）を開発パートナーとして一貫して利用しています。ただし、思いつきで公開しているわけではなく、機能追加のたびに実際に動作確認を行い、別ユーザーアカウントでのクリーン環境テストや、Appleの正式な公証など正規の配布手順も踏んだ上で提供しています。

より詳しい操作方法は [manual.ja.md](./manual.ja.md) をご覧ください（[English manual](./manual.md) もあります）。<br>
アプリ本体もv1.3.0〜、設定画面から表示言語（自動／日本語／English）を切り替えられます。

📖 開発の進捗・雑感は [開発日記](https://ocoe-puipui.github.io/diary/) でも公開しています。

## アプリケーションの起動方法
ローカル環境でアプリを起動する手順です。

### 1. 依存パッケージのインストール
Python（3.10 以上推奨）環境のターミナルまたは仮想環境で、以下のコマンドを実行して必要なライブラリをインストールします。

```bash
pip install -r requirements.txt
```

### 2. アプリの起動
ファイルが配置されているディレクトリに移動し、エントリーポイントである `main.py` を実行します。

```bash
python main.py
```

## ファイル構成
このプロジェクトはモジュール化された以下の5つのコアファイルで構成されています。

#### 1. `main.py` (エントリーポイント)
アプリケーションの起動のエントリーポイントです。GUIを初期化し、メインウィンドウを表示します。

#### 2. `app.py` (コアロジック)
PySide6によるUI全体、イベント制御、検索（フィルタリング）・並び替え・グループ表示、スライドショー機能、クリップボード連携、ダーク/ライトモードの切替、設定ダイアログなどを担います。

#### 3. `importer.py` (データ抽出)
Pillowを使用して画像からメタデータを自動抽出し、さらにファイル内容のSHA-256ハッシュを計算し、フォルダ同期処理を行います。

#### 4. `database.py` （データベース）
SQLite3を用いて画像情報やインポート履歴を永続化します。自動マイグレーション機能により、DBの構造変更にも柔軟に対応できます。

#### 5. `.gitignore` (除外設定)
リポジトリから除外するキャッシュファイル、仮想環境 (`venv`)、データベースファイル (`image_metadata*.db`)、現在使用中のデータベースを記録するポインタファイル (`current_db.txt`) を指定します。

## 機能

#### 1. フォルダ同期 ＆ インポート

**差分自動取り込み** <br>
一度インポートしたフォルダのパスを記憶し、「Sync（同期）」ボタンで新しい画像だけを高速に追加スキャンします。フォルダ取り込み・同期とも、サブフォルダは対象外です（指定フォルダ直下のみ）。

**取り込み順序の確認** <br>
フォルダ取り込み時、ファイル名順・作成日時順・更新日時順（各昇順/降順）から取り込み順序を選べます。設定画面で「毎回確認」（既定）か「前回使用した順序を自動選択」かを選択可能です。

**個別ファイルの取り込み** <br>
フォルダ単位だけでなく、画像ファイルを個別に複数選択して取り込むこともできます。フォルダ全体を対象にしたくない場合に便利です。

**連番による自動命名** <br>
新規に取り込んだ画像の「名前」には、既定で実ファイル名ではなく連番（例: CG_00001）が自動で付けられます。プレフィックス・桁数・末尾に付けるアペンド文字列は設定画面から変更できます。プレフィックス＋アペンドの組み合わせごとに採番が独立しており、削除しても番号は再利用されません（設定画面から手動でリセットすることも可能です）。設定画面のチェックボックスで連番命名規則自体をオフにし、実際のファイル名をそのまま「名前」として取り込むこともできます。

**重複防止** <br>
ファイルパスの重複と、ファイル内容の **SHA-256ハッシュ値** を比較し、同じ画像（コピー）の登録を自動でスキップします。取り込み時の確認画面で「中身が同じ画像も取り込む」を選ぶと、あえて別レコードとして取り込むこともできます（既定はスキップ）。

**バックグラウンド処理** <br>
大量インポート時、進捗ダイアログ（件数・現在のファイル名）を表示しながら動作し、必要であれば途中でキャンセルすることもできます。

#### 2. ビューワー

**パラメータの自動分離** <br>
画像内のメタデータから「プロンプト」「ネガティブプロンプト」「その他詳細情報（Steps, Sampler, Seed等）」を自動で判別・分離して表示します。さらに Steps・Sampler・Scheduler・CFG scale・Seed・Size は、使用モデル欄の下に個別項目としても表示可能です（設定画面のチェックボックスで項目ごとに表示/非表示を切替）。Seedの値の横には、値だけをコピーできる専用ボタンがあります。

**対応フォーマット** <br>
Stable Diffusion WebUI（Automatic1111 / Forge）・NovelAIに加え、ComfyUIで生成された画像にも対応しています。ComfyUIはワークフロー構成がユーザーごとに大きく異なるため、プロンプト等の自動抽出は行わず、ワークフロー全体（LoRA・バッチサイズ等の設定を含む）を「その他パラメータ」欄にそのまま保存します。

**ワンクリックのコピー** 各プロンプトエリアの横にあるボタンを押し、クリップボードへテキストをコピーできます。

**星評価** <br>
星にマウスを乗せるとプレビュー表示され、クリックで0〜5段階の評価を設定できます。同じ星をもう一度クリックすると評価を解除できます。

**プレビュー表示の切替** <br>
非表示・標準・コンパクト・全画面の4種類からプレビューサイズを選べます。「非表示」を選ぶと、メタデータ編集エリアを広く使えます。全画面表示中も、画像送り・スライドショー・再生速度の操作はそのまま行えます。

**プレビュー画像のドラッグ&ドロップ** <br>
プレビュー中の画像は、Finder（エクスプローラー）や他のアプリへ直接ドラッグ&ドロップしてコピーを取り出せます。

**ファイル名の編集** <br>
「名前」とは別に、パソコン上の実際のファイル名も直接編集・変更（リネーム）できます。同じフォルダ内での重複はできません。

**名前の自由な編集** <br>
アプリ内で管理する「名前」は、実際のファイル名とは別に自由に編集でき、検索用のタグのような使い方もできます（重複可）。

**変更をコピーとして保存** <br>
オリジナルのファイルは変更せず、編集した内容を持つ新しいコピーとして好きな場所に保存できます。

**メタデータのクリア** <br>
使用モデル・プロンプト・ネガティブプロンプト・その他メタデータの各欄は、ワンクリックでクリアできます。「変更を保存」を押すまでは確定しないため、誤操作しても安心です。

**編集フォームの表示/非表示切替** <br>
使用モデル・プロンプト・ネガティブプロンプト・その他メタデータの各欄は、一時的に非表示にできます。非表示にした分の高さは、残りの表示中の欄に自動で均等に配分されます。使用モデル欄の表示/非表示に合わせて、生成パラメータの個別表示欄も連動して表示/非表示が切り替わります。

**画像リストの案内表示** <br>
画像が1件も登録されていない時は「画像を取り込んでください」、外部からのドラッグ中は「ドラッグ&ドロップしてください」の案内をリスト内に表示します（現在ドラッグ&ドロップでの取り込み自体は一時的に無効化されています。詳細は下記をご覧ください）。

**アイコンデザイン** <br>
主要なボタン・見出しに、Google Material Symbolsベースのアイコンを採用しています。テーマ（ダーク/ライト）や、アクセントカラー（青）背景のボタン上でも視認しやすいよう、状況に応じてアイコンの色が自動で切り替わります。

#### 3. デスクトップ連携＆操作性

**安全なドラッグ＆ドロップ** アプリ内の画像リストから、OSのフォルダ（Finder/エクスプローラー等）や別のアプリへ画像をドラッグして持ち出せます。コピーのみが実行されます。（オリジナルは保護）

**右クリックメニュー** <br>
画像を右クリックすると、Finder（エクスプローラー）での表示、ファイル自体のコピー、パスのコピーが行えます。複数選択にも対応しています。

**ダーク/ライトモードの切替** <br>
macOSの外観モードに自動追従するほか、設定画面から「自動/ダーク固定/ライト固定」を手動で選ぶこともできます。

**左右パネルの配置切替** <br>
設定画面から、検索・取り込み・リスト等を左右どちらに表示するか（標準／反転）を選べます。右利き・左利きなど、操作しやすい配置に切り替えられます。

**編集ロック機能** <br>
右クリックメニューから画像ごとに編集をロック/解除できます。ロック中は削除や情報変更ができなくなり、誤操作から大事な画像を守れます。

**削除画像の同期除外** <br>
リストから削除した画像は、以後「同期」を実行しても自動では復活しません。再度取り込みたい場合は、「フォルダを取り込む」または「画像ファイルを取り込む」で明示的に選び直してください。

**設定画面（⚙）** <br>
連番命名規則（オン/オフ切替、プレフィックス・桁数・アペンド文字列、組み合わせごとの採番リセット）の編集、生成パラメータの個別表示項目の切替、テーマ・左右パネル配置の手動切り替え、フォルダ取り込み時の順序設定、データベースの初期化、画像一覧のCSVエクスポート、複数データベースの作成・切り替え、設定全体のリセットをまとめた設定画面を用意しています。ヘルプ・リリースノートへのリンクは、メインウィンドウ上部（設定ボタンの左）から開けます。

**複数データベースの切り替え** <br>
用途ごとに複数のデータベース（`image_metadata.db`、`image_metadata2.db`...）を作成し、切り替えて使うことができます。作成・切り替えの操作は設定画面から行い、切り替え時はアプリが自動的に再起動します。データベースの保存先は`~/Library/Application Support/AIImageViewer/`です。

#### 4. 検索＆並び替え＆スライドショー

**リアルタイム絞り込み** <br>
入力したキーワード（「名前」欄・実際のファイル名・プロンプト・ネガティブプロンプト・その他メタデータ）や星の数で、リストをフィルタリングします。

**並び替え** <br>
名前順・作成日順・編集日順・取り込み日時順・評価順・ファイルサイズ順から選べ、昇順/降順は独立したボタンで切り替えられます。グリッド表示とリスト表示もワンクリックで切り替え可能です。

**サムネイルサイズ調整** <br>
グリッド表示時、タイルの大きさを「小/中/大」の3段階から選べます。「大」では場所・日時も表示されます。

**フォルダ別グループ表示** <br>
リスト表示時、画像をフォルダ別にグループ化して表示できます。見出し行をクリックすると、そのフォルダの画像一覧を折りたたみ/展開できます（▼/▶で状態を表示）。見出し行を右クリックすると、ドラッグ&ドロップでフォルダの並び順を変更できます。ON/OFF・折りたたみ状態・並び順は次回起動時まで記憶されます。

**スライドショー** <br>
タイマーによる自動再生機能を搭載。再生速度は0.5倍〜2倍の範囲で0.25刻みに調整でき、検索で絞り込んだ画像だけを自動巡回させることも可能です。

**読書モード（見開き表示）** <br>
選択した画像と同じフォルダ内の画像を、本のように2枚並べて全画面表示するモードです（「フォルダ別グループ表示」が有効な時のみ利用可能）。左開き/右開きの切り替え、スライドバー・矢印キー・画面端クリックによるページめくり、背景のダーク/ライト切り替えに対応しています。左右のページを画面中央でぴったり突き合わせる「中央詰め表示」への切り替えも可能です。閲覧専用モードです。

## 既知の制限事項

**ドラッグ&ドロップでの取り込みは一時的に無効化中** <br>
外部（Finder等）から画像リストへ直接ドラッグ&ドロップして取り込む機能は、動作が不安定だったため一時的に無効化しています。画像の取り込みは「フォルダを取り込む」「画像を取り込む」ボタンをご利用ください。
