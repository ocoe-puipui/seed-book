## Seed Book (AI image browser)
主に生成AI（Stable Diffusionなど）で作成された画像とそのメタデータ（プロンプト、ネガティブプロンプト、モデルパラメータ等）を一元管理・閲覧するデスクトップアプリです。<br>
Stability Matrixの出力に最適化されており、他のファイル管理ツールとの併用にも向いています。

> **開発の背景** <br>
> Stability Matrixの生成画像は「inference」フォルダに一括出力されますが、標準プレビューが見づらかったため開発しました。オリジナルを一切変更せず、大量の画像を快適にプレビューできることを目指しています。Stability Matrix専用ではなく、汎用画像ビューワーとしても使えます。
>
> **開発について** <br>
> 私はプログラミングの専門知識を持たず、AIとの対話でコードを設計・実装する「バイブコーディング」でこのアプリを開発しています。AnthropicのClaude（Sonnet）を開発パートナーとして利用していますが、機能追加のたびに動作確認を行い、別ユーザーアカウントでのクリーン環境テストやAppleの正式な公証など、正規の配布手順を踏んで提供しています。

より詳しい操作方法は [manual.ja.md](./manual.ja.md) をご覧ください（[English manual](./manual.md) もあります）。<br>
アプリ本体もv1.3.0〜、設定画面から表示言語（自動／日本語／English）を切り替えられます。

📖 開発の進捗・雑感は [開発日記](https://ocoe-puipui.github.io/diary/) でも公開しています。

## Technical Stack

**Language** Python 3.10+

**GUI Framework** PySide6 (Qt for Python)

**Image Processing** Pillow (PIL)

**Database** SQLite3

**OS Compatibility** Cross-platform compatible

**AI Coding Partner** Anthropic's Claude (Sonnet)

## アプリケーションの起動方法
ローカル環境でアプリを起動する手順です。

### 1. 依存パッケージのインストール
ターミナルまたは仮想環境（Python 3.10以上推奨）で、以下のコマンドを実行して必要なライブラリをインストールします。

```bash
pip install -r requirements.txt
```

### 2. アプリの起動
ファイルが配置されているディレクトリに移動し、エントリーポイントである `main.py` を実行します。

```bash
python main.py
```

## ファイル構成
このプロジェクトはモジュール化された以下の5つのコアファイルで構成されています。

#### 1. `main.py` (エントリーポイント)
アプリ起動のエントリーポイント。GUIを初期化し、メインウィンドウを表示します。

#### 2. `app.py` (コアロジック)
PySide6によるUI全体、イベント制御、検索・並び替え・グループ表示、スライドショー機能、クリップボード連携、テーマ切替、設定ダイアログなどを担います。

#### 3. `importer.py` (データ抽出)
Pillowで画像からメタデータを自動抽出し、SHA-256ハッシュを計算、フォルダ同期処理を行います。

#### 4. `database.py` （データベース）
SQLite3で画像情報やインポート履歴を永続化。自動マイグレーション機能により構造変更にも柔軟に対応します。

#### 5. `.gitignore` (除外設定)
リポジトリから除外するキャッシュファイル、仮想環境 (`venv`)、データベースファイル (`image_metadata*.db`)、使用中DBを記録するポインタファイル (`current_db.txt`) を指定します。

## 機能

#### 1. フォルダ同期 ＆ インポート

**差分自動取り込み** <br>
インポート済みフォルダのパスを記憶し、「Sync」で新しい画像だけを追加スキャンします。対象は指定フォルダ直下のみ（サブフォルダ除外）。

**取り込み順序の確認** <br>
ファイル名順・作成日時順・更新日時順（昇順/降順）から取り込み順序を選択可能。「毎回確認」（既定）か「前回の順序を自動選択」かも設定できます。

**個別ファイルの取り込み** <br>
フォルダ単位だけでなく、画像ファイルを個別に複数選択して取り込みも可能です。

**連番による自動命名** <br>
新規取り込み画像の「名前」は既定で連番（例: CG_00001）になります。プレフィックス・桁数・アペンド文字列は設定画面で変更可能で、組み合わせごとに採番が独立し、削除しても番号は再利用されません（手動リセット可）。オフにすれば実ファイル名をそのまま使用。プレフィックス/アペンド欄では{date}・{folder name}プレースホルダーをクリック挿入できます。

**重複防止** <br>
**SHA-256ハッシュ値** で内容を比較し同一画像を自動スキップ。取り込み確認画面で「中身が同じ画像も取り込む」を選べば別レコードとして取り込めます（既定はスキップ）。

**バックグラウンド処理** <br>
大量インポート時は進捗ダイアログを表示し、途中でキャンセルできます。

#### 2. ビューワー

**パラメータの自動分離** <br>
画像メタデータから「プロンプト」「ネガティブプロンプト」「その他詳細情報」を自動分離表示。Steps・Sampler・Scheduler・CFG scale・Seed・Sizeは使用モデル欄下に個別表示も可能（項目ごとに設定で切替）。Seed横には専用コピーボタンあり。

**対応フォーマット** <br>
Stable Diffusion WebUI（Automatic1111/Forge）・NovelAI・ComfyUIに対応。ComfyUIはワークフローが多様なため自動抽出は行わず、全体をそのまま「その他パラメータ」欄に保存します。

**ワンクリックのコピー** 各プロンプトエリア横のボタンでクリップボードへコピーできます。

**星評価** <br>
マウスオーバーでプレビュー、クリックで0〜5段階を設定。同じ星を再クリックで解除。

**プレビュー表示の切替** <br>
非表示・標準・コンパクト・全画面の4種。「非表示」で編集エリアを広く使え、全画面中も画像送り・スライドショー操作が可能です。

**プレビュー画像のドラッグ&ドロップ** <br>
プレビュー中の画像をFinder等へ直接ドラッグ&ドロップしてコピーを取り出せます。

**ファイル名の編集** <br>
「名前」とは別に、実ファイル名も直接編集・リネームできます（同フォルダ内での重複不可）。

**名前の自由な編集** <br>
アプリ内「名前」は実ファイル名と別に自由編集でき、検索用タグのようにも使えます（重複可）。

**変更をコピーとして保存** <br>
オリジナルは変更せず、編集内容を新しいコピーとして好きな場所に保存できます。

**メタデータのクリア** <br>
使用モデル・プロンプト・ネガティブプロンプト・その他の各欄をワンクリックでクリアでき、「変更を保存」を押すまでは未確定です。

**編集フォームの表示/非表示切替** <br>
各メタデータ欄を個別に非表示にでき、空いた高さは残りの欄へ自動配分されます。使用モデル欄の表示/非表示に生成パラメータ欄も連動。

**画像リストの案内表示** <br>
未登録時・ドラッグ中にそれぞれ案内文を表示します（ドラッグ&ドロップでの取り込み自体は現在一時的に無効化）。

**アイコンデザイン** <br>
主要ボタン・見出しにGoogle Material Symbolsベースのアイコンを採用し、テーマや背景色に応じて自動調整されます。

#### 3. デスクトップ連携＆操作性

**安全なドラッグ＆ドロップ** 画像リストからOSのフォルダや別アプリへドラッグして持ち出せます。コピーのみ実行され、オリジナルは保護されます。

**右クリックメニュー** <br>
Finderでの表示、ファイル/パスのコピーが行えます。複数選択対応。

**ダーク/ライトモードの切替** <br>
macOSの外観設定に自動追従、または設定画面から「自動/ダーク固定/ライト固定」を選択可能。

**左右パネルの配置切替** <br>
検索・取り込み・リスト等を左右どちらに表示するか（標準／反転）を選べ、利き手に合わせた配置に切替できます。

**編集ロック機能** <br>
右クリックから画像ごとに編集をロック/解除。ロック中は削除・変更ができず誤操作を防げます。

**削除画像の同期除外** <br>
リストから削除した画像は「同期」実行後も自動では復活しません。再取り込みするには明示的な選び直しが必要です。

**設定画面（⚙）** <br>
連番命名規則の編集、生成パラメータの個別表示切替、テーマ・左右パネル配置の手動切替、フォルダ取り込み順序、DB初期化、CSVエクスポート、複数DBの作成・切替、設定全体のリセットをまとめて提供。ヘルプ・リリースノートはメインウィンドウ上部から開けます。

**複数データベースの切り替え** <br>
用途ごとに複数のデータベース（`image_metadata.db`、`image_metadata2.db`...）を作成・切替でき、切替はアプリの自動再起動を伴います。保存先は`~/Library/Application Support/AIImageViewer/`。

#### 4. 検索＆並び替え＆スライドショー

**リアルタイム絞り込み** <br>
キーワード（名前・実ファイル名・プロンプト・ネガティブプロンプト・その他メタデータ）や星の数でリストを絞り込みます。

**並び替え** <br>
名前順・作成日順・編集日順・取り込み日時順・評価順・ファイルサイズ順から選べ、昇順/降順を独立切替可能。グリッド/リスト表示もワンクリック切替。

**サムネイルサイズ調整** <br>
グリッド表示のタイルを「小/中/大」から選択。「大」では場所・日時も表示されます。

**フォルダ別グループ表示** <br>
リスト表示で画像をフォルダ別にグループ化。見出しクリックで折りたたみ/展開（▼/▶）、右クリックでドラッグ&ドロップ並び替え。ON/OFF・折りたたみ状態・並び順は次回起動時まで記憶されます。

**スライドショー** <br>
タイマーによる自動再生。速度は0.5〜2倍を0.25刻みで調整でき、検索で絞り込んだ画像だけの巡回も可能です。

**読書モード（見開き表示）** <br>
選択画像と同じフォルダ内の画像を、本のように2枚並べて全画面表示（「フォルダ別グループ表示」時、またはアルバム内画像選択時に利用可）。左開き/右開き切替、スライドバー・矢印キー・端クリックでのページめくり、背景ダーク/ライト切替、中央詰め表示に対応。閲覧専用。

#### 5. アルバム（仮想フォルダ）機能（v1.4〜）

**実フォルダを横断してまとめる仮想的な入れ物** <br>
実際のフォルダ構成とは別に画像を自由にまとめられる「アルバム」を作成できます。1枚の画像を複数アルバムに所属させることも可能。画像リスト表示とアルバム表示は上部の切り替えボタンで排他的に切り替えます。

**アルバムへの追加方法** <br>
右クリックメニューの「アルバムに追加」（既存選択または新規作成）、または画像をアルバム行へドラッグ&ドロップします。

**アルバム作成時に自動採番ルールも設定可能** <br>
「アルバムを作成する」ダイアログでアルバム名と同時に専用の自動採番ルール（プレフィックス・桁数・アペンド）を設定できます（既定オフ）。{アルバム名}・{日付}プレースホルダーが使えます。

**アルバム一覧の操作感はフォルダ別グループ表示と共通** <br>
見出しクリックで展開/折りたたみ、右クリック（または「⋯」）でメニューを開けます。並び順編集、名前変更、すべて開く/折りたたむ、一括書き出し（連番リネーム）、専用採番設定、削除に対応。

**アルバム専用の自動採番ルール** <br>
設定するとそのアルバムの一括リネーム・連番書き出しに優先適用されます（フォルダ/全体ルールとは独立、同時適用なし）。1枚のみの選択でも使用可能。

**Finderへの書き出し** <br>
アルバムや展開中の画像をFinderへドラッグ&ドロップで書き出せます。アルバムは実フォルダを持たないため、ドラッグ時に一時フォルダへ実体化されます。元のファイル名がそのまま使われ、採番ルールは適用されません（適用したい場合は右クリックの一括書き出しを利用）。

**検索・並び替えとの連携** <br>
アルバム表示中も検索フォームで開いているアルバム内の画像を絞り込め、並び替えもアルバム表示に反映されます。

## 既知の制限事項

**ドラッグ&ドロップでの取り込みは一時的に無効化中** <br>
外部（Finder等）から画像リストへの直接ドラッグ&ドロップ取り込みは、動作が不安定なため無効化しています。「フォルダを取り込む」「画像を取り込む」ボタンをご利用ください。

**フォルダ別グループ表示で、折りたたみ操作後に画像送り（前へ/次へ）が反応しないことがある** <br>
表示中の画像を含むフォルダを折りたたんだ後、画像送りが正しく反応しないことがあります。致命的な不具合ではないため、修正は今後の課題としています。
