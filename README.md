## Seed Book (AI image browser)
This desktop application is designed for the centralized management and viewing of images—primarily those generated by AI tools such as Stable Diffusion—along with their associated metadata (including prompts, negative prompts, model parameters, etc.). It is specifically optimized for images created within Stability Matrix, making it highly convenient to use alongside other file management utilities.

> **Why I Built This** <br>
> Images generated by Stability Matrix are dumped into a single "inference" folder, and I found the default preview layout hard to browse. That frustration led me to build this app: a tool that lets you comfortably preview large batches of images at any time, without ever modifying the original files. While it started as a companion for Stability Matrix, it also works well as a general-purpose image viewer for any use case.
>
> **About the Development Process** <br>
> I don't have a professional programming background. This app is built through what's sometimes called "vibe coding" — designing and implementing features through ongoing dialogue with AI coding tools, rather than writing code myself. Specifically, I use Anthropic's Claude (Sonnet) as my coding partner throughout development. That said, nothing is shipped carelessly: every feature is manually tested after implementation, builds are verified in a clean separate user account, and releases go through the proper Apple notarization process before distribution.

For more detailed usage instructions, see [manual.md](./manual.md) (a [Japanese manual](./manual.ja.md) is also available).<br>
Since v1.3.0, the app itself can also switch its display language (Auto / Japanese / English) from Settings.

📖 Development progress and notes are also shared on the [dev diary](https://ocoe-puipui.github.io/diary/) (Japanese only).

## How to Run the Application
Follow these steps to launch the application in your local environment.

### 1. Install Dependencies
Run the following command in your terminal (or virtual environment) to install the required libraries.

```bash
pip install -r requirements.txt
```

### 2. Launch the App
Navigate to the directory where the files are located and execute `main.py`.

```bash
python main.py
```

## File Structure & Roles
This project consists of five core files, cleanly modularized by role:

#### 1. `main.py` (Entry Point)
The main execution entry point. Initializes and displays the GUI application window.

#### 2. `app.py` (Core Logic)
The core logic handler for PySide6. Manages the entire UI, event handling, real-time filtering, sorting, grouping, slideshow functionality, clipboard integration, theme switching, and the settings dialog.

#### 3. `importer.py` (Data Extraction)
Extracts metadata via Pillow, computes the file's SHA-256 hash, and handles bulk import synchronization.

#### 4. `database.py` (Database)
Manages the SQLite3 database, performing auto-migrations and ensuring data integrity.

#### 5. `.gitignore` (Exclusions)
Specifies files to be excluded from version control (e.g., `venv`, `__pycache__`, `image_metadata*.db`, and `current_db.txt`, which records which database is currently active).

## Features

#### 1. Sync & Import

**Differential Auto-Import** <br>
Remembers imported folder paths and quickly scans only new images when the "Sync" button is pressed. Both folder import and sync only scan files directly inside the selected folder (subfolders are excluded).

**Import Order Confirmation** <br>
When importing a folder, choose the order to import files in (by name, creation date, or modification date, ascending or descending). Settings let you choose between confirming every time (default) or automatically reusing the last order.

**Individual File Import** <br>
In addition to folder-based import, you can select and import individual image files (multiple selection supported) when you don't want to bring in an entire folder.

**Automatic Sequential Naming** <br>
By default, newly imported images are automatically named with a sequence number (e.g., CG_00001) instead of the original filename. The prefix, digit count, and an optional append string are all configurable in Settings. Each prefix+append combination keeps its own independent counter, and numbers are never reused after deletion (though the counter can be manually reset from Settings). Sequential naming itself can also be toggled off from Settings, in which case the actual file name is used as-is. The prefix/append fields support `{date}` and `{folder name}` placeholders — click the placeholder link to insert it at your cursor's current field (prefix or append), with an underscore automatically added on the appropriate side.

**Per-Folder Naming Override** <br>
Right-click a folder header in "Group by Folder" view to set a folder-specific prefix/digit-count/append rule that overrides the app-wide default. This override applies not only to new imports into that folder, but also to "Bulk Rename" and "Bulk Export with Rename" performed on existing images in that folder.

**Selectable Import Formats** <br>
PNG / JPG / JPEG / WEBP are enabled by default; GIF / BMP / TIFF can be enabled via checkboxes (GIF is shown as a still frame of the first frame). The checkbox row has its own show/hide toggle to keep the list area uncluttered.

**Duplicate Prevention** <br>
Compares file content via **SHA-256 hash**, automatically skipping duplicates even if they have different filenames. An option in the import confirmation dialog lets you opt in to importing duplicate content as separate records instead (skipping is the default).

**Background Processing** <br>
Displays a real-time progress dialog during large imports, with the option to cancel partway through if needed.

#### 2. Viewer

**Automatic Parameter Separation** <br>
Automatically parses and separates metadata from the image into distinct fields like Prompt, Negative Prompt, and Other Details (Steps, Sampler, Seed, etc.). Steps, Sampler, Scheduler, CFG scale, Seed, and Size can additionally be displayed as individual fields below the model name, each toggleable from Settings. A dedicated copy button next to the Seed value lets you copy just that value.

**Supported Formats** <br>
In addition to Stable Diffusion WebUI (Automatic1111 / Forge) and NovelAI, images generated with ComfyUI are also supported. Since ComfyUI workflows vary widely between users, prompts are not auto-extracted; instead, the full workflow (including LoRA, batch size, and other settings) is preserved as-is in the "Other Parameters / Metadata / EXIF Info" field.

**Camera EXIF Display** <br>
For photos where no AI-generation metadata is found (JPEG/TIFF/WEBP, which natively support EXIF), the app automatically reads and formats camera EXIF data — make, model, date taken, exposure time, F-number, ISO, focal length, and GPS coordinates — into the "Other Parameters / Metadata / EXIF Info" field. PNG/GIF/BMP don't support this, since they don't carry native EXIF.

**Per-Image Memo Field** <br>
A free-text memo field at the top of the edit area, independent of any AI-generation metadata and stored purely for your own in-app use. Its content is also included in search.

**One-Click Copy** Pressing the button next to any prompt field instantly copies its content to the clipboard.

**Star Rating** <br>
Hover over the stars for a live preview, then click to set a rating from 0 to 5. Clicking the same star again clears the rating.

**Preview Display Modes** <br>
Choose between Hidden, Standard, Compact, and Fullscreen preview sizes. "Hidden" frees up more space for the metadata editing area. Navigation, slideshow playback, and speed controls remain fully functional even in fullscreen mode.

**Drag Out the Preview Image** <br>
The currently previewed image can be dragged directly out to Finder/Explorer or another app to copy it out.

**Rename Actual Files** <br>
In addition to the in-app "Name" field, you can directly edit and rename the actual file on disk. Duplicate filenames are not allowed within the same folder.

**Freely Editable Name** <br>
The in-app "Name" field can be edited independently of the actual filename, and can even be reused across images (e.g., as a search tag).

**Save as New Copy** <br>
Save your edits as a brand-new copy at a location of your choice, without modifying the original file.

**Bulk Rename (In-App "Name" Only)** <br>
Select multiple images, right-click, and choose "Bulk Rename (Sequential)..." to renumber only the in-app "Name" field for all of them using your sequential naming rule (or a folder-specific override, if set). **The actual filenames on disk are never touched.** Locked images are skipped, and each `{folder name}` group gets its own counter starting at 1.

**Bulk Export with Rename (Actual Filenames)** <br>
Select images (or a whole folder header) and choose "Bulk Export with Rename (Sequential)..." to copy the originals — unchanged — into a folder you choose, with the **copies'** actual filenames sequentially renamed per your naming rule. This is kept clearly distinct from Bulk Rename above so it's always clear which one affects the in-app name vs. the real file on disk.

**Clear Metadata Fields** <br>
Instantly clear the model, prompt, negative prompt, memo, or other metadata fields with one click. Changes stay pending until you press "Save."

**Toggle Metadata Fields** <br>
Temporarily hide any of the memo, model, prompt, negative prompt, or other metadata fields — each has its own show/hide button. The freed space is automatically distributed evenly among the remaining visible fields. The individual generation-parameter display row also follows the show/hide state of the model field. A single button near the top-right (next to the settings icon) can show/hide all of these fields — plus the import-format checkbox row — at once.

**List Placeholder Messages** <br>
Shows a friendly message when the list is empty or when files are being dragged over it (drag-and-drop import itself is currently temporarily disabled — see below).

**Icon Design** <br>
Major buttons and section headers use icons based on Google Material Symbols. Icon colors automatically adjust for visibility against the current theme and against accent-colored (blue) button backgrounds.

#### 3. UX & OS Integration

**Safe Drag & Drop** Images can be dragged from the app's list to OS folders or other applications. Only a copy is created, protecting the original file.

**Right-Click Menu** <br>
Right-click any image to reveal it in Finder/Explorer, copy the file itself, or copy its path. Multi-selection is supported.

**Dark/Light Theme** <br>
Automatically follows the macOS appearance setting, or can be manually fixed to Dark or Light from the Settings dialog.

**Panel Layout Switching** <br>
From Settings, choose whether search/import/list etc. are shown on the left or right (Standard / Mirrored) — useful for right-handed vs. left-handed workflows.

**Edit Lock** <br>
Lock or unlock editing per image from the right-click menu. Locked images cannot be deleted or modified, protecting important images from accidental changes.

**Sync-Safe Deletion** <br>
Images removed from the list stay removed even after running "Sync" again. They only return if explicitly re-imported via folder or file import.

**Settings Dialog (⚙)** <br>
A gear-icon settings dialog provides sequential naming rule configuration (on/off toggle, prefix, digits, append string, and per-combination counter reset), individual parameter display toggles, manual theme and panel-layout switching, folder import order preferences, database reset, CSV export of the image list, creating and switching between multiple databases, and a full settings reset. Help and release notes can be opened from the top of the main window (to the left of the settings button).

**Multiple Database Switching** <br>
You can create and switch between multiple databases (`image_metadata.db`, `image_metadata2.db`, ...) for different purposes. Creating and switching are done from Settings; switching automatically restarts the app. Databases are stored in `~/Library/Application Support/AIImageViewer/`.

#### 4. Search, Sort & Slideshow

**Real-time Filtering** <br>
Instantly filters the list based on keywords entered in the search bar (the app's "name" field, the actual file name, prompt, negative prompt, or other metadata) or by star rating.

**Sorting** <br>
Sort by name, creation date, last-edited date, import date, rating, or file size, with ascending/descending toggled independently. Instantly switch between grid and list views.

**Adjustable Thumbnail Size** <br>
In grid view, choose from three tile sizes (Small/Medium/Large). The Large size also shows the file location and date.

**Group by Folder** <br>
In list view, images can be grouped under folder headers. Click a folder header to collapse or expand its images (indicated by ▼/▶). Right-click a folder header to reorder folders via drag-and-drop. The ON/OFF state, collapsed state, and folder order are all remembered across restarts.

**Slideshow Playback** <br>
Features automatic playback via a timer. Playback speed can be adjusted from 0.5x to 2x in 0.25 increments, and you can cycle through only the images matching your current search filter.

**Reading Mode (Two-Page Spread View)** <br>
Displays images from the same folder as the selected image side-by-side across the full screen, like an open book (available only when "Group by Folder" is enabled). Supports left-to-right/right-to-left reading direction, page turning via the slider, arrow keys, or screen-edge clicks, and an independent dark/light background toggle. Also supports a "center-aligned" display that joins the two pages together at the screen's center, like a physical book. View-only mode.

## Known Limitations

**Drag & Drop Import Temporarily Disabled** <br>
Dragging files directly from Finder onto the image list is currently disabled due to unstable behavior. Please use the "Import Folder" / "Import Images" buttons instead.
